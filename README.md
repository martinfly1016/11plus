# 11+ Maths Year 5 互动学习

中文讲解 + 英文术语与考题的交互式学习网页合集，每一课都是「学方法 → 互动练习 → 期末挑战」。

## 目录

- **Lesson 1** — [大数、四舍五入与负数](lesson01-place-value-rounding-negatives/)
  读写与比较到 1,000,000 的数、四舍五入到 10 / 100 / 1,000 / 10,000 / 100,000；负数、数轴与温差计算。含 20 道期末挑战题。
- **Lesson 2** — [加强：四舍五入与负数 · 新课：罗马数字、因数倍数与质数](lesson02-roman-numerals-factors-primes/)
  四舍五入加强（反向题、陷阱题、应用题）与负数加强（混合排序、双负数温差、跨 0 计算）；罗马数字到 1,000；因数、倍数、质数与简单 HCF / LCM。含 20 道期末挑战题（四项各 5 题）。

后续课程会依次添加到本仓库，首页 `index.html` 为总目录。
